# Project documentation

* `architecture/`: descriptions of the Cloud IXL execution flow.
* `icd/`: the project interface contract used for Cloud IXL/OC integration.
* `reference/eulynx/`: external EULYNX reference documents.
* `thesis/`: local thesis drafts; this directory remains ignored by Git.

The repository is a laboratory prototype. These documents do not constitute a
normative implementation or certification claim.

# Optional and legacy material

This directory contains material that is not part of the main Cloud IXL to
Object Controller execution path.

* `examples/`: standalone RaSTA, SCI-LS, SCI-P, and logging examples.
* `diagnostics/`: manual UDP, redundancy, and multiplexer stress programs.
* `java/`: the JNI wrapper and its example clients.
* `protocols/scip/`: optional SCI-P implementation for point controllers.
* `config/examples/`: configuration files used only by optional examples.
* `docker-rasta-demo/`: the historical containerised RaSTA/SCI example.
* `legacy-build/`: the former Gradle and Doxygen build files.
* `docs/rasta-study/`: upstream and exploratory RaSTA/SCI documentation.

These files support learning, diagnostics, or compatibility work. They are not
evidence of compliance with RaSTA, SCI-LS, EULYNX, EN 50159, or SIL4.
